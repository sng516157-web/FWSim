**Decisions made this milestone (documented, facts-based):**

1. **Suspended model = rigid massless pivot** (no string slack, no free
   attach-point rotation). Exact for the small-oscillation swing mode tested
   here (`ω = sqrt(m g d_cm / I_pivot)`); a flexible-string plant is a
   different model, deferred.
2. **Foil frame mapping corrected.** The stage file's provisional mapping
   (`θ_fs ≡ θ_sb`, `T_R ↔ T_front`) does NOT hold. Verified by test:
   `x_fs = x_sb`, `z_fs = −y_sb`, `θ_fs = −θ_sb`, `T_front = k·f_L`,
   `T_back = k·f_R`. The sandbox's thrust law `(T sinθ, T cosθ)` in a y-up
   world maps to a sign-flipped pitch in NED, and the torque sign follows.
   Any sign error fails `test_foil_rhs_equivalence` (< 1e-12).
3. **`m_a = 0` allowed** in `ReducedModelParams` only with
   `lock_abdomen=True` (M singular otherwise) — used by the foil's
   degenerate single-body limit (stage file §2.4a permits this).
4. **Actuator torque mapping** `Q_act = [0,0,0,τ]ᵀ` with no explicit Q_θ
   term (virtual work on the relative coordinate; reaction is implicit
   through the mass-matrix coupling). `reduced_model_spec.md` wording fixed
   accordingly.
5. Wing mass is not in the schema (wings are massless at M2) — recorded as a
   known limitation; revisit when mass properties matter quantitatively.

**Pendulum frequency comparison (experiment config):** analytical
ω = 13.2135 rad/s (T₀ = 0.475513 s); measured 0.475854 s at φ₀ = 0.1 rad —
consistent with the finite-amplitude correction (predicted 0.475810 s with
the φ₀²/16 term; remaining 4e-5 s is crossing-estimator bias in the
experiment, eliminated in the test by event detection).

**Foil caveat (stage file §2.4a):** this is a kernel cross-check against a
toy model — the sandbox's `T = k·f` law is synthetic (`source: estimated`),
not physics. It validates mass/inertia/force-law/lever-arm assembly and the
frame mapping; it validates **nothing** about aerodynamics.

  The suspended model is a rigid-pivot plant; no claim is made about
  free-flight behaviour of the reduced or full model.
